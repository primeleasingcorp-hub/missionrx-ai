# MissionRx AI

## Pharmacy & 340B Advisory

Stronger operations for community care.

Consulting website for FQHCs, community health centers, and IHS / Tribal health organizations.

## Preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## GitHub Pages

Publish the main branch from the repository root. No build step is required.

## Features

Sage green design, six workflow topics, expandable details, and a locally generated consultation brief. The form does not send inquiries. Beacon automation is a consulting service description, not a live claims-upload integration.

Font licensing and attribution are in assets/.
